# 保险公司财报 RAG 问答知识库

本项目为《人工智能与数据分析》课程项目。

项目以10家保险公司2025年度报告/年度信息披露报告为研究对象，构建一个面向保险财报研究的 RAG（Retrieval-Augmented Generation，检索增强生成）问答系统。

系统支持对保险公司财报进行自然语言提问，并返回基于原始财报证据生成的答案，同时提供公司、章节、PDF页码和 Chunk ID 等出处信息。

---

## 1. 项目目标

本项目主要完成以下工作：

1. 收集10家保险公司的年度报告/年度信息披露报告；
2. 从 PDF 中提取文本，并保留公司、年份、章节、PDF页码等元数据；
3. 对财报中的表格进行行列结构恢复；
4. 建立 Vector Search + BM25 混合检索；
5. 使用 RRF（Reciprocal Rank Fusion）融合两类检索结果；
6. 使用 DeepSeek 根据检索证据生成答案；
7. 使用 Streamlit 构建可交互的财报问答页面；
8. 设计10道评测题，对系统的召回和回答效果进行分析。

## 3. 系统流程

整体流程如下：

PDF 年报

→ 文本提取

→ 章节识别

→ 文本切块

→ 表格检测与行列恢复

→ Chunk 元数据构建

→ 向量 Embedding

→ Vector Search + BM25

→ RRF 融合排序

→ DeepSeek 基于证据回答

→ Streamlit 页面展示答案和出处

每个 Chunk 尽量保留以下元数据：

- 公司
- 年份
- 章节
- PDF页码
- Chunk ID
- 内容类型（text / table）

---

## 4. 表格处理

保险财报包含大量财务表格。

本项目首先自动检测表格候选区域，再根据行列结构进行恢复，并对结果进行质量检查。

共检测到 715 个候选表格。

经过质量规则筛选后，303 个高置信候选表格用于进一步生成结构化表格 Chunk；对于较长表格进行分块后，最终得到 348 个表格 Chunk。

复杂的跨页表格、合并单元格和无明显边框表格仍可能出现恢复失败，因此未将所有候选表格直接加入 RAG，而是保留原始文本作为补充。

---

## 5. 检索方法

系统同时使用两种检索方法：

### Vector Search

使用 Qwen3-Embedding-0.6B 将 Chunk 转换为向量，通过语义相似度寻找相关内容。

### BM25

使用 BM25 进行关键词匹配，以提高保险专业术语、公司名称和财务指标的精确检索能力。

### RRF

最终通过 Reciprocal Rank Fusion（RRF）融合 Vector Search 和 BM25 的排序结果。

这种组合能够同时利用语义相似性和关键词匹配能力。

---

## 6. RAG 回答

检索得到的高相关 Chunk 被组织为上下文并发送给 DeepSeek。

回答阶段要求模型：

- 仅依据检索证据回答；
- 数字尽量保持原始口径；
- 证据不足时明确说明；
- 跨公司比较时区分不同公司；
- 指标名称或统计口径可能不同时进行提示；
- 给出公司、章节、PDF页码和 Chunk ID 等出处。
